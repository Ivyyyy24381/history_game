## 核心设计

### 一句话

鲁米的一生是**从「书里的答案」走到「书外面」**：前半生是一个越来越好的学者，
1244 年一个陌生人问了一个书里没有答案的问题，后半生他把答案写成了诗。

所以整条线的交互语法是：**前半（1219–1240）考「你知道什么」，后半（1244–1273）考「你愿不愿意放下你知道的」**。
沙姆斯那一关（沉默作答）是全线的铰链——玩家第一次被要求「不按规则出牌」。

### 视角：儿子写的传记（轻框架）

但丁线用薄伽丘讲坛做框架；鲁米线用更轻的一层：
**1291 年，科尼亚。鲁米的儿子苏丹·瓦拉德在写《开端之书》**——现存最早的鲁米传记，作者本人就是见证者。

- 每个事件开场一个 `transition`，瓦拉德一两句话引入（不说教，只抛问题）。
- **史料等级是显式的**：瓦拉德亲眼见过的 → 不标；后世阿夫拉基《圣徒传》（1318–1353）的传说 → 画面左上角挂「传说」标签（phaseKit 的 `legend` 字段）。
  玩家一路都在练「这件事谁说的、他在不在场」——这本身就是历史课。
- 成本：每事件 1 个 transition + 1 张书房背景（全线复用）+ 瓦拉德晚年立绘 1 张。

### 第 5 层：「这段经历后来成了哪一行诗」

沿用但丁 V2 的思路：每个事件结尾，把刚经历的事和一行鲁米的诗连起来（`link_match` 或 `predict_reveal`）。
诗句一律用 **Nicholson 英译（1925–40，公有领域）为底本自译**，标「本作试译」；**不用 Coleman Barks 译本、不用国内现代中译本**（有版权）；不用网上流传的伪托名言。

## 1219 四十头骆驼

**地点**：撒马尔罕 → 呼罗珊大道　**时期**：少年流亡　**状态**：离家　**鲁米**：12 岁

### 设计意图

让玩家先有一个「家」再失去它。离开的原因要让玩家**自己从闲谈里拼**：蒙古人的消息、
父亲和朝廷的不和、家里的书——不是一句「为躲避蒙古人」就讲完。带什么走，是这一关唯一的动作，
而那三样东西会在后面的事件里回来（缺水 / 父亲叹息丢了的书）。

### Phase 1 · transition · 开端之书 ·

- **背景**：`walad_study_1291.png`（1291 年科尼亚书房，灯下一个白须老人伏案书写，窗外绿色穹顶的轮廓；**全线复用**）
- **苏丹·瓦拉德**：「我父亲十二岁那年，全家离开了撒马尔罕。后来的人说是为了躲蒙古人。可我祖父走的时候，蒙古人还没到——他为什么要走？」

### Phase 2 · explore · 撒马尔罕的市集（4 NPC）○

- **背景**：`samarkand_bazaar.png`（13 世纪初撒马尔罕的有顶市集，砖砌穹顶，丝绸与瓜果摊，驼队从远处城门进来，清晨斜光）
- 🔑 商队头领：「讹答剌那边出事了，蒙古大汗派来的商队被杀了个精光。大汗不会善罢甘休的。」（1218 讹答剌事件）
- 🔑 老学生：「巴哈丁先生在清真寺讲经，句句都在骂朝廷那帮人。宫里的人早就不高兴了。」
- 瓜贩：「撒马尔罕的瓜，巴格达的哈里发都要吃！」（撒马尔罕的富庶，氛围）
- 🔑 母亲穆敏娜：「你父亲说，要去麦加朝觐。东西只能带最要紧的。」
- 通过：`requiredTalks: 3`

### Phase 3 · evidence_select · 为什么要走？◆

- **claim**：「巴哈丁带全家离开，原因不止一个。」
- **pick**：2
- 支持 ①：蒙古使团在讹答剌被杀，大战迫在眉睫 ——「外面的危险」
- 支持 ②：他在讲经时公开批评朝廷的学者，和宫里关系很僵 ——「里面的不和」
- 干扰（真但不相干）：撒马尔罕是丝绸之路上最富的城市之一 —— why：「这解释了为什么大家舍不得走，不解释为什么要走。」
- 干扰（真，但对结论不利）：离开时，蒙古人还要再过好几年才打到撒马尔罕 —— why：「这条恰恰说明，只用『躲蒙古人』解释不了他们走得这么早。」
- 注：出走年份学界有争议（约 1212–1219）；这一幕只要求「原因不止一个」，不断言具体年份。

## 1220 内沙布尔的香料铺

**地点**：内沙布尔　**时期**：少年流亡　**状态**：被看见　**鲁米**：13 岁

### 设计意图

一个伟大的老诗人看了这个孩子一眼——传说。这一关的认知动作不在「相遇」，在阿塔尔讲的那个故事：
三十只鸟飞过七个山谷去找神鸟，最后发现神鸟就是它们自己。**这是全线主题的第一次出现**，玩家现在猜，1244 年会懂。

### Phase 1 · explore · 药香铺 ○

- **背景**：`nishapur_attar_shop.png`（内沙布尔的药香铺，墙上一格格药材与香料，铜秤，玫瑰水瓶，午后光线穿过木格窗；**不画店主**）
- 「阿塔尔」这个名字本来就是「卖香料和药的人」。NPC：阿塔尔（老年，白须，药师围裙）、学徒、父亲巴哈丁。
- 阿塔尔：「我白天称药，晚上写诗。药治身上的病，诗治别的。」
- 通过：和阿塔尔说话

### Phase 2 · predict_reveal · 百鸟会议 ▲　`legend: 阿塔尔《百鸟会议》`

- **背景**：`birds_seven_valleys.png`（细密画风的七重山谷，一群鸟排成长列飞越，最前面是戴胜鸟，山谷一重比一重荒凉，远处一面湖水如镜）
- **situation**：「阿塔尔给孩子讲了一个故事：世上所有的鸟，要去找它们的王——神鸟西摩格。戴胜鸟带路，要飞过七个山谷。一路上，鸟一只只找借口掉队。最后只剩三十只，飞到了西摩格的宫殿。」
- **question**：「它们见到的西摩格，是什么样子？」
- 选项：一只比山还大的金色神鸟 / 带路的戴胜鸟自己 / 湖面上映出的——它们自己 / 宫殿是空的，根本没有西摩格
- **actual**：湖面上映出的——它们自己
- **reveal**：「波斯语里，『西摩格』（sī murgh）拆开来念，就是『三十只鸟』。它们要找的王，就是飞到终点的它们自己。」
- **consequence**：「阿塔尔是鲁米之前最重要的波斯神秘主义诗人之一。这个故事鲁米一辈子都记得：你要找的东西，也许一直在你身上。——记住这个，二十四年后会用到。」

### Phase 3 · transition · 一本书和一句话 ·　`legend: 传说（道拉特沙等后世记载）`

- **背景**：同 Phase 1
- 阿塔尔把自己的《秘密之书》送给孩子，对巴哈丁说：「这孩子将来会在世上点起一把火。」
- 瓦拉德（旁白）：「这件事我父亲从没跟我提过。它是后来的人写的。你可以不信——但你看，后来确实着了火。」
- 同年：蒙古军攻破内沙布尔（1221），传说阿塔尔死于屠城。（`announcement` 形式）

### 资源需求

## 1225 拉兰达的婚礼与葬礼

**地点**：巴格达 → 麦加 → 大马士革 → 马拉蒂亚 → 埃尔津詹 → 拉兰达（今卡拉曼）　**时期**：少年流亡　**状态**：同一年的喜与悲　**鲁米**：18 岁

### 设计意图

流浪了六七年，一家人终于在安纳托利亚一座小城停下。同一段时间里，十八岁的鲁米娶妻、母亲去世——
这一关用**同一个动作**（写字）做两件事：写婚约、写墓志。操作一样，情绪完全相反。

### Phase 1 · map_travel · 朝觐与西行 ○

- **背景**：`route_1221_hajj.png`（内沙布尔 → 巴格达 → 麦加 → 大马士革 → 马拉蒂亚 → 埃尔津詹 → 拉兰达，一条向西南再折向西北的长线）
- 途经：巴格达「世界最大的城市之一，哈里发的都城。」· 麦加「朝觐。」· 大马士革 · 马拉蒂亚 · 埃尔津詹「塞尔柱人的地界。」· 拉兰达「停下来了。」
- 注：路线细节各家记载不一，途经点只取主流说法，地图上不标年份。

### Phase 2 · explore · 拉兰达的院子 ○

- **背景**：`larende_courtyard.png`（安纳托利亚小城的石砌院落，葡萄架，远处是雪山与土黄色平原，婚礼的彩布挂在廊下）
- NPC：高哈尔（新娘，撒马尔罕老友的女儿）、母亲穆敏娜（病中，坐在廊下）、父亲
- 母亲：「我们从撒马尔罕走到这里，走了六年。你在路上长大了。」

### Phase 3 · predict_reveal · 婚约怎么写？▲

> 第二批做成 `trace`（鼠标描摹书法）；第一版用 predict_reveal，零新代码。

- **背景**：`marriage_contract_desk.png`（矮书桌上一张空白婚约纸，芦苇笔、墨壶、撒沙罐，旁边一支红烛）
- **question**：「波斯文写婚约，笔从哪边起？」
- 选项：从左往右，和汉字横排一样 / 从右往左 / 从上往下，一列一列写
- **actual**：从右往左
- **reveal**：「波斯文用阿拉伯字母，从右往左写，书也从我们眼里的『最后一页』翻起。」
- **consequence**：「鲁米后来用这种文字写的诗，光《玛斯纳维》就有约两万五千联。」

### Phase 4 · comic_reveal · 同一年 ·（点击揭开，4 格）

- **背景**：`comic_larende_year.png`（连环画长图 4 格：婚礼上的新人与乐师 / 母亲在廊下病倒 / 送葬的队伍走出城门 / 年轻的鲁米在墓前）
- 结尾字幕：「母亲葬在拉兰达。七百多年后，卡拉曼城里还有一座小清真寺，当地人叫它『鲁米母亲的清真寺』。」

### Phase 5 · predict_reveal · 墓志写什么？▲

- **question**：「如果让你给母亲写一句墓志，你会写——」（三个选项都对，没有 actual 对错；`sameNote`/`diffNote` 同文）

- ⚠️ 工程注意：predict_reveal 需要一个 actual；这里设成玩家可能选的任意一项都给同一段 reveal（数据上 actual 随便指一项，sameNote = diffNote）。

## 1231 父亲的讲席

**地点**：科尼亚　**时期**：科尼亚学者　**状态**：接过担子　**鲁米**：24 岁

### 设计意图

塞尔柱苏丹把这家人请到了首都科尼亚。三年后父亲去世，二十四岁的鲁米接过讲席——学生们等着看他行不行。
这一关建立「学者鲁米」：他很会，而且越来越会。**必须让玩家先相信「学问就是答案」**，1244 才打得碎。

### Phase 1 · transition · 苏丹的邀请 ·

- **背景**：`konya_citadel_1228.png`（13 世纪科尼亚，阿拉丁山丘上的清真寺与宫殿，城墙，远处平原上的商队驿站）

### Phase 3 · predict_reveal · 送葬的人 ▲

- **situation**：「1273 年 12 月 17 日，鲁米去世。第二天送葬，队伍里有穆斯林，也有基督徒和犹太人。」
- **question**：「为什么基督徒和犹太人也来了？」
- 选项：苏丹下令全城都要来 / 他们都受过鲁米的教诲，觉得他也是自己的老师 / 只是来看热闹
- **actual**：第二项
- **reveal**：据阿夫拉基记载，有人问他们为何而来，他们大意是说：「我们从他身上，懂得了我们自己经书里的道理。」（本作意译，出处为后世传记，标「传说」）
- **consequence**：「科尼亚当时住着突厥人、波斯人、希腊人、亚美尼亚人和犹太人。鲁米讲的寓言，谁都听得懂。」——回收 1258 四人争葡萄。
